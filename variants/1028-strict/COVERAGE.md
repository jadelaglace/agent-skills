## 技术纠错依据与限制

- Node.js 官方 HTTP 文档 response.end：每个响应必须结束；writeHead 仅发头不代表结束。requestTimeout/headersTimeout/socket 终止提供可按真实协议使用的有界手段。本变体不指定所有拒绝必须先 resume。
- WebGL 1.0 官方规格的 Context Creation and Drawing Buffer Presentation / WebGLContextAttributes：preserveDrawingBuffer=false 下，呈现/合成后的缓冲清除语义与具体读回时机有关；默认framebuffer并非一律不可读。透明值也不能单独证明“没画”。C14要求控制样例与实际绑定/时机，不能把这些说明当本项目已完成GPU实验。
- 参考日期 2026-11-01。来源：Node.js https://nodejs.org/api/http.html#responseenddata-encoding-callback 与 Khronos https://registry.khronos.org/webgl/specs/latest/1.0/ （编辑草案，按实际项目采用版本核对）。本轮只核对官方文档，不声称跑过真实HTTP或WebGL实现。
