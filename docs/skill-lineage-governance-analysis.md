## 3. 仓库索引：分析完成，正式索引未创建

### 最小结构

建议仓库根新增 SKILLS-INDEX.md（正式实施时），README只保留一个导航链接。先用一个可审查的Markdown台账，不同时维护JSON/YAML/HTML多份手写真源，也不造调度器或自动发布器。变多且确有自动化消费者时，再考虑机器可读单源生成展示。

按“技能×内容线”一行，而非只按名称一行；同一技能的主线、严格变体、原文资料可明确对应。原文归入资料区，不占运行技能数量。版本字段引用实际入口，不靠索引暗中改版本。

### 建议记录的8组信息

| 组 | 最少字段 | 防止的混淆 |
| --- | --- | --- |
| 身份与位置 | 名称、职责、内容线、相对路径、对应技能 | 同名混线、资料冒充可运行技能 |
| 设计取向 | 能力信任型/严格核证型；用户指定的强/弱模型背景 | 风格不是模型排行榜，严格不是自动质量认证 |
| 主干与吸收来源 | 本机历史提交或截图批次；后续借鉴/重构；可追溯证据；未知项 | 作者、生成模型、主干、参考材料不是同一件事 |
| 内容身份 | 独立技能版本、最近核对的Git提交或工作树身份 | 仓库日期标签不等于技能SemVer，未提交不能假指向HEAD内容 |
| 仓库状态 | 仅工作树/已提交；push或仓库发布已核实/未核实 | 在Git工作区里不等于已经公开上传 |
| 本机发布观察 | 未安装/已安装相同/已安装漂移/未核；检查位置、日期、哈希证据 | 历史“安装过”不等于现在仍安装或与源码一致 |
| 启用与使用状态 | 有无可发现入口；当前会话是否加载（可为未知） | 安装、可发现、自动调用、实际加载不是一个布尔值 |
| 分发意图与限制 | 本机主线/仅存档/暂不安装/待决定；授权依据、验证范围与缺口 | 计划“要发”不等于已经发；测试通过不等于发布授权 |

公开索引用相对路径、脱敏证据引用和观察时间；不写私有原文、会话正文、凭据或私人环境路径。作者按用户声明记录为用户自建；具体生成模型/版本未知就未知，不能因“GPT训练风格”反推作者模型。

### 更新与核对边界

索引是可读登记，不是运行时权威或安装开关。内容变更、安装/卸载、分发决策或发布时更新受影响行，记录实际观察与证据；没做过的检查写未核。过时/冲突时以最新授权决定“应该怎样”，以只读回读判断“实际上怎样”，显式记录偏差，不能让磁盘覆盖意图。

实施后应检查所有登记路径可达、版本与入口一致、disabled项没有偷偷安装、已安装项身份匹配、公开字段无私密信息。索引检查不应重复安装、重跑整个项目测试或自动push。
