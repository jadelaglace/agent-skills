## 精炼增量与刻意不改

- product-docs：恢复基线后去掉必选 Goal/API/枚举/钩子校验顺序与固定单任务队列机制；入口只概括任务可恢复、完成不重放、局部失败、共享最小写原则；细则单归 lifecycle。greenfield 对应去掉平台耦合。
- architecture：仅补重要选型三问、状态/操作的终止与失败清理边界；数据权威、可重建、集成实证在基线已有，不重复搬运。
- code-quality：仅补先读及命名占用检查、测量/环境相关结论需实际路径；ctx、幂等、资源、证据与风险测试在基线已有。
- design-standards：仅补真实主体/内容与诊断副本不能代替原始交付验收；不默认禁用户所需 logo/文字，不强加全站一图一用。
- 其余 references 与 UI 元数据为历史原样，无流程大清单反灌。本机版本沿既有最高线滚 patch：1.0.5 / 1.1.1 / 1.1.1 / 1.1.1；未升 minor/major。
